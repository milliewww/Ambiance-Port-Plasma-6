Ambiance KDE Window Decoration ported to KDE Plasma 6. 

Tested on KDE Plasma 6.8.2, not tested on any other version of KDE.

Install by extracting the zip and copying the ambianceport folder to ~/.local/share/aurorae/themes/
Then just select it in System Settings. 

Original Theme: https://www.opendesktop.org/p/1002700/
